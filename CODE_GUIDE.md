# WhimsyWorkshop — Generated Code Guide

This folder contains the CSS and JavaScript generated by WhimsyWorkshop.

## CSS Usage

- **`base.css`** — Refer to this file for shared styles, utility classes, CSS variables, and available class names.
- **Component CSS files** — Styles for individual components, such as buttons, inputs, tabs, and modals.

Use the class names defined in the CSS files directly in your HTML.

For example, use the appropriate `layout-*` class for layout-related styling. Refer to `base.css` for the available classes and their definitions.

## JavaScript Usage

Refer to the generated JavaScript files for component-specific configuration and behaviour.

Keep the required files together and preserve their expected loading order when integrating them into a project.

## Customisation

The generated CSS and JavaScript can be edited directly to suit your project. Keep a backup of the original files if you want to preserve the initial generated output.
